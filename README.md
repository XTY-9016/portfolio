## 项目索引

### 01 · 高温钢管表面缺陷检测平台
**FloEFD 稳态共轭传热（CHT）+ 辐射换热 + 水冷与空调复合冷却结构设计** ｜ 校内课题 2025.03–2025.11

- **问题与判据**：挤压钢管产线在成型初期钢管表面约 600℃，需对 R100–250mm 钢管做实时全角度表面缺陷检测；
  检测盒内工业相机与线激光传感器的工作温度上限为 **+70℃**，环境 20℃，盒体采用铝板镶嵌铜管水冷，
  后部大圆孔接工业空调（送风 10℃）。
- **做了什么**：建立稳态 CHT 模型（固体域含铝板、铜管盘管、相机、传感器与隔热材料；流体域含盒内空气与外部环境）；
  完成 **1/10、1/5、原网格三档网格无关性验证**；根据温度场结论改进结构。
- **结果**：温度场仿真发现检测窗口面积过大、热辐射进入量过高 → 在不影响检测视野的前提下**缩小窗口尺寸，
  并将原单一窗口改为相机、传感器各设独立窗口**；同时完成风冷/水冷回路与隔热结构设计，
  使关键部件工作温度低于器件承受上限 +70℃；**产品样机已落地**。
- **材料**：3 张云图 + 2 段动画 → [`projects/01-高温钢管检测平台/`](projects/01-高温钢管检测平台/)

### 02 · 封闭式滚动电镀成套装备
**机械结构设计 + 静力学/热学仿真校核 + 标准件选型** ｜ 校内课题 2023.10–2024.08

- **工艺与总体方案**：把原「开放式 + 多重溶液浸泡」改为「**封闭式电镀箱 + 溶液工序控制 + 滚动式动态电镀**」，
  **电镀均匀性提高 25%、单件平均缩短 18min**；完成机架、箱体主结构与机械传动设计，输出三维模型、工程图纸及 BOM。
- **关键结构设计**：
  - **上下料机械爪**：四爪抓取装置，由 4.4 kN 大推力气缸经 Y 形中间拉动组件将推力一分为四传给四只实心金属抓指；
    四爪斜 45° 交叉分布，避免起吊载荷过度集中在下方唯一机械臂上；气缸与机械臂连接座之间以直角焊接支架过渡，使推杆只承受轴向压力。
  - **内筒抓取与抗弯加强**：端部环形双斜面楔槽抓取环实现轴向自定位；针对夹持时施力点集中于筒身一端、
    弯矩过大的问题，设计**环形阵列八根贯穿筒身的抗弯钢筋与三组保持架**，把弯矩由筒身转移至钢筋。
  - **标准件选型与校核**：减速电机、保护圈、轴承、密封圈等，依据传动负载、转速、扭矩、寿命、耐腐蚀及耐温要求确定规格。
- **仿真校核**：外箱体应力/变形/刚度校核（据此改为桁架形式）、机械爪夹臂与销轴及连接座螺栓组强度校核、
  内筒夹持两类失效校核、电镀箱电热反应热分析。
- **结果**：参与装配、调试与工艺验证，解决密封与传动问题；**样机已落地**。
- **材料**：4 张图 + 1 段上下料动画 → [`projects/02-电镀装备/`](projects/02-电镀装备/)

### 03 · 不锈钢板带力学性能预测（硕士学位论文）
**企业委托课题 ｜ 机理建模 + 试验对标 + 数据驱动方法 + 工程软件** ｜ 2024.12–2026.05

- **数据集与机理建模**：构建 201 不锈钢冷轧连退产线「工艺-组织-性能」数据集（40 余项工艺参数 + EBSD 微观组织
  平均晶粒尺寸 13.11–90.85μm + 拉伸试验 GB/T 228.1-2021）；建立 Sellars + Burke-Turnbull 晶粒尺寸演化唯象模型
  （拟合优度 R²=0.89）与 Hall-Petch + Swift-Voce 真应力-真应变分段本构模型，屈服强度计算值与实测对照
  **MAE 23.82 MPa、RMSE 27.75 MPa**。
- **参数敏感性与预测建模**：完成 40 余项工艺参数的相关性分析与敏感性排序，识别终轧压下率为核心变量；
  XGBoost + 随机森林融合模型实现力学性能预测，屈服/抗拉/延伸率 **R² 达 0.941 / 0.913 / 0.922**。
- **工程工具**：基于 PySide2 + Qt Designer 开发数据分析与预测软件（数据读取分析、参数配置、训练监控、
  批量预测与 Bootstrap 置信区间可视化导出），支持产线自主完成新钢种建模-评估-预测，已交付使用。
- **材料**：整理中 → [`projects/03-力学性能预测/`](projects/03-力学性能预测/)
